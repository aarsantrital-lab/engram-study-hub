grow.js — unit tests

The GROW unit model, the illusion-of-competence cross-check, and the “what should I study now?” decision.

Must be served over http:// — ES modules are blocked on file://.
From study-hub/: python -m http.server 8000 then open http://localhost:8000/js/tests/grow.test.html
Section B writes to this origin’s local storage. It is skipped automatically when real study data is already present (a non-empty review log or any saved self-rating), and it restores the keys it touched afterwards. Nothing here can delete study data.
